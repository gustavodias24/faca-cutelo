# Cutelo Chef Forjado

Landing page responsiva desenvolvida com Python e Flask.

## Como executar

1. Crie e ative um ambiente virtual.
2. Instale as dependências: `pip install -r requirements.txt`
3. Inicie o servidor: `python app.py`
4. Acesse `http://127.0.0.1:5000`

O endereço do checkout fica centralizado na constante `CHECKOUT_URL`, no início de `app.py`.
